# CREW CONNECT

Employee Information System

## Project Description

CREW CONNECT is an Employee Information System designed to manage employee information, attendance records, leave requests, and other employee-related activities.

## Developed By

Our Group Project Team

## Individual Contribution

This project aims to help local restaurants manage employee information, attendance records, and leave requests through a centralized information system. The system provides separate access for authorized staff and regular employees to make employee record management more organized and accessible.
